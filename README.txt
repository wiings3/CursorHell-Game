CURSOR HELL — LEVEL 1 VERTICAL SLICE v0.2
==========================================

PLAY INSTANTLY
1. Double-click RUN_GAME.bat
   OR
2. Double-click PLAY_NOW.html

No install or web server is required. Click the game to capture the mouse.

CONTROLS
- Mouse: move the player. The player IS the cursor.
- Esc: release mouse / pause
- Click: start or resume
- R: restart

LEVEL 1 — FIRST CONTACT
- 45-second introductory/tutorial level.
- First 6 seconds are hazard-free so the player can learn movement.
- Phase 1 introduces slow left/right projectiles.
- Phase 2 introduces all four arena edges.
- Phase 3 introduces the optional Graze scoring mechanic.
- Final 5 seconds slightly increase pressure without turning into a bullet wall.
- Every projectile is telegraphed with an orange warning arrow and lane guide.
- No vortex, curved projectiles, aimed bursts, or dense patterns in Level 1.
- One projectile hit still ends the run, so the tutorial teaches the real collision rule.

GODOT SOURCE

The Godot version mirrors the standalone prototype's Level 1 structure.
